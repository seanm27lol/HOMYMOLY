# Superseded exploratory record

> **SUPERSEDED — 2026-08-24. Do not cite this document for terminology,
> numerical evidence, controls, or inferential claims.**

This path formerly contained an exploratory narrative titled “Exactness as a
prior on a learned conversion.” That narrative predated the frozen campaign and
used names that the audit found mathematically inaccurate:

- the learned operator is a degree-changing **edge-to-cycle lifting**, not a
  degree-preserving chain-map conversion;
- `mean((W B1^T)^2)` is a **boundary-compatibility penalty**, not sequence
  exactness;
- `exp(-2 sigma_min(W))` is a **singular-value cone surrogate**, not
  mapping-cone homology; and
- normalized pairwise-distance MSE is an **RTD-inspired distance surrogate**,
  not published RTD or SRTD.

The exploratory seed identities were not retained, so overlap with the later
frozen seed block cannot be audited. Several exploratory control values also
lacked a generating script and machine-readable result. Repeating the obsolete
narrative here risked allowing stale terminology and unauditable numbers to be
quoted out of context; its full text remains recoverable from Git history.
